# Stock AI formulas (English): detection list

Read this for long drafts, deep edits, and audit-only requests. **A candidate list, not a banned-word list.**

## How to use

- **Two tiers.** `Strong` = act on one sighting. `Weak` = act only when clustered (2+ in a paragraph, 4+ in the piece).
- **Three scales.** Word (trigger) → sentence (skeleton) → piece (every section uses the same skeleton). Piece-level hits matter more than word-level hits.
- **False-positive guards** (any one cancels the hit):
  1. inside a quotation, title, proper name, code, legal text, or standard definition;
  2. the passage is *discussing* the phrase ("I've stopped using the word 'leverage'");
  3. genre convention (legal boilerplate, a required abstract structure);
  4. the writer's own sample does it consistently;
  5. the sentence is carrying real logic (cause, concession, condition, anaphora).
- **A hit is not a license to edit.** Ask first: "what does the reader lose if this goes?" Nothing → filler.

## 1. World-staging openers (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| In today's fast-paced world / In an era of… | background that adds no information | the background *is* the subject | open on the problem or a scene |
| As we navigate the ever-evolving landscape of… | decorative grandeur | never as written | delete |
| Since the dawn of time / Throughout history | vague time claim | give real dates instead | name the period |
| It's no secret that… | consensus used in place of evidence | the consensus is contested | delete, or give evidence |
| In recent years, X has become increasingly important | importance asserted, not shown | there is a measurable trend | give the metric |
| With the rapid development of… | fake causal opener | the trend is real and relevant | delete or state the trend with data |

## 2. Paragraph openers with no referent (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| It's worth noting that / It's important to note that | self-applied importance sticker | the point genuinely contradicts expectation | delete the frame, state the fact |
| Notably / Importantly / Crucially / Interestingly | adverb asserting significance | rarely | delete |
| Moreover / Furthermore / Additionally (stacked) | logic declared instead of shown | real addition | delete, let order do the work |
| Indeed | emphasis with no content | confirming a cited claim | delete |
| Of course | pre-empting an objection nobody made | real concession | delete or make the concession concrete |
| In fact / Actually | implies the previous sentence was false | real surface-vs-reality gap | state both sides |

## 3. Fake-insight setups (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| Here's the thing / Here's what I mean | stages candor | never | state the point |
| The truth is / The reality is | announces hidden truth | never | state the claim |
| What most people get wrong / The part everyone misses | flatters the writer as lone expert | never | make the claim stand alone |
| The uncomfortable truth | same | never | delete |
| Let me be clear | same | never | delete |
| It turns out that | implies discovery | a real finding with a source | give the source |

## 4. Binary contrasts (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| It's not X, it's Y / This isn't about X, it's about Y | the negative names something nobody claimed | X is a real misconception the reader holds | state Y only |
| It's not just X, but Y | inflates by addition | both halves carry information | delete the first half |
| Less about X, more about Y | same | real trade-off | give the trade-off conditions |
| X isn't a tool, it's a mirror | aphorism dressed as analysis | never | state the actual claim |
| The question isn't X, it's Y | reframes without evidence | you show why X fails | show it, or state Y |
| Not only… but also… | mechanical escalation | both clauses factual and distinct | split into two sentences |

## 5. Importance inflation (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| plays a crucial / vital / pivotal role | importance instead of function | never as a phrase | say what it does |
| serves as a testament to | praise in place of fact | never | delete |
| stands as a / marks a pivotal moment | historical weight not earned | a verifiable turning point | state the event |
| underscores / highlights / reflects (the importance of) | trailing significance | the source itself says this | keep the fact, cut the rider |
| solidifies its position / paves the way for | unverified prediction | evidence of the outcome | delete |
| has become an integral part of | vague integration | specific date and mechanism | say when and how |
| In an ever-changing landscape | atmosphere | never | delete |

## 6. Vague attribution (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| Experts agree / Many argue / It is widely believed | unnamed authority | a named expert exists | name them |
| Studies show / Research suggests | source-free science | the user supplied the study | cite author, year, journal |
| Industry reports indicate / According to industry sources | fake provenance | a real named report | name it; otherwise delete |
| It has been said that | passive attribution | a real attributable quote | attribute or delete |
| Critics have noted | unnamed critics | named critics | name them |

## 7. Hedging with no referent (strong, but do not over-cut)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| To some extent / In some ways | hedge without scope | a real boundary follows | give the boundary |
| It's important to note that… may vary | meta-level disclaimer | real variability with cases | name the cases |
| Generally speaking / For the most part | softens everything | a real exception exists | give the exception |
| Arguably | removes the claim | the writer is genuinely weighing | state the argument |
| In many cases / In certain situations | countable but uncounted | you can count them | give the count |
| This may or may not be the case | contentless | never | delete |

> Preserve scope, sample limits, and legal/safety qualifiers. Stacked hedges are the tell; a single precise qualifier is a human habit.

## 8. Metadiscourse and navigation (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| In this article / This section will cover | narration instead of content | required by the format | delete; headings suffice |
| Let's dive in / Let's explore / Let's break this down | run-up | never | delete |
| Without further ado | same | never | delete |
| As mentioned earlier / As we saw above | re-anchoring | long document, one use | keep one; use a specific pointer otherwise |
| In other words / Put simply / That is to say | restatement | the second version is genuinely clearer | keep the clearer one, delete the frame |
| Here's what you need to know | preview | never | delete |

## 9. Rhetorical setups (weak, clustered)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| What if I told you… | manufactured suspense | speaking script | state the fact |
| Think about it / Consider this | instruction to think | never | delete |
| Plot twist / But here's the catch | entertainment cadence | never in expository prose | state the caveat |
| The result? / The answer? (fragment + reveal) | staged reveal | never | write the sentence |
| Sound familiar? | false intimacy | genuine audience address | delete |

## 10. Uplift closers (strong)

| Formula | Why it's a tell | Keep when | Fix |
|---|---|---|---|
| In conclusion / In summary / Ultimately | recap the reader just read | long report needing a summary | delete |
| At the end of the day | filler | never | delete |
| The future looks bright / Only time will tell | prediction without content | concrete plans exist | state the plans |
| This is just the beginning | promotional | never | delete |
| Let's wait and see | empty | never | delete |
| The possibilities are endless | empty | never | delete |

## 11. Weak verbs and nominalizations (weak, clustered)

| Formula | Fix |
|---|---|
| serves as / functions as / acts as / represents | is |
| boasts / features / offers / maintains | has, or the specific verb |
| made a decision / conducted an analysis / performed an evaluation | decided, analyzed, evaluated |
| has the ability to / is capable of | can |
| provides support for | supports |
| in order to | to |

## 12. Shallow `-ing` riders (strong)

`highlighting, underscoring, emphasizing, reflecting, showcasing, symbolizing, ensuring, fostering, contributing to, encompassing`

An `-ing` clause bolted onto a fact to make it sound deeper. Keep only if the source supports the claim the rider makes. Example: "The launch adds file search, highlighting the team's commitment to workflows" → "The launch adds file search, so users can find old drafts without leaving the editor."

## 13. Sales language (strong)

`nestled in the heart of, rich cultural heritage, stunning natural beauty, breathtaking, renowned, must-visit, vibrant, diverse array of, a hidden gem, world-class`

State what the thing is. "Nestled in the breathtaking region of X, Y stands as a vibrant town with a rich cultural heritage" → "Y is a town in the X region."

## 14. AI-favored vocabulary (weak alone, strong in clusters)

delve, tapestry, landscape (abstract), realm, robust (figurative), leverage, seamless, pivotal, meticulous, intricate, multifaceted, foster, navigate (figurative), embark, unleash, harness, elevate, empower, streamline, cutting-edge, paradigm shift, game changer, testament, underscore, showcase, vibrant, profound, groundbreaking, transformative, holistic, synergy, ecosystem (figurative), framework (figurative), journey (figurative), unlock, supercharge, ever-evolving, unprecedented, reimagine, revolutionize.

**One of these is not a tell.** A formal word outside this list is not a tell either. Check density and co-occurrence.

## Audit output format

```
Location: para 3, sentence 2
Snippet: "It's worth noting that the approach may, to some extent, improve outcomes."
Family: paragraph-opener (strong) + hedge-without-referent (strong)
Problem: frame with no referent; hedge with no scope
Fix: delete the frame; replace the hedge with the actual condition
```

Order by impact on the reader's judgment. If there are no findings, say so.
