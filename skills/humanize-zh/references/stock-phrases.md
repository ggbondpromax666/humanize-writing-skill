# AI 固定句式检测清单（中文）

> **出处**：综合自 [anti-defensive-writing-zh](https://github.com/Devilyuu/anti-defensive-writing-zh) `references/patterns-zh.md`（C/E 层）、[blader/humanizer](https://github.com/blader/humanizer) §1–§25、[no-ai-slop](https://github.com/petergyang/no-ai-slop) 词表，按功能重排并补保留条件。具体句式属公共观察，不归任何一方独有。见 [ATTRIBUTION.md](https://github.com/ggbondpromax666/humanize-writing-skill/blob/main/ATTRIBUTION.md)。

长文、深改、只诊断时读。**这是候选信号表，不是禁词表。**

## 使用说明

- **两级阈值**：标 `强` 的见一处就处理；标 `弱` 的成片出现（同段≥2 处或全文≥4 处）才处理。
- **三层看**：词（触发词）→ 句（骨架）→ 篇（每段都用同一骨架）。篇章层命中比词层更值得改。
- **误报护栏**（下面任一成立就不算）：
  1. 在引文、标题、专名、代码、法规条文、标准定义里；
  2. 段落本身在**讨论**这个词（"我最近戒掉了'赋能'这个词"）；
  3. 文体规范要求（公文的"进一步""切实"，期刊的"本文结构如下"，任务书的分点，合同条款）；
  4. 作者旧稿里一贯如此（样本频率优先）；
  5. 该句确实承担逻辑（真实因果、让步、条件、指代）。
- **命中不是改写依据**：先回答"删掉后读者少知道了什么"。什么都没少 → 才是填充。

## 1. 开场垫话（强）

从宏大背景起笔，推迟进入问题。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 在当今……的时代／在……的大背景下 | 背景不提供信息 | 背景本身是论证对象 | 直接从问题、场景或判断开始 |
| 随着……的快速发展／随着……的不断深入 | 假因果开场 | 后半句讲的是真实趋势变化 | 删前半，或把趋势写成带数据的句子 |
| 众所周知／毋庸置疑／不言而喻 | 用共识替代证据 | 该共识会引发争议时 | 删；有证据就写证据 |
| 自古以来／长期以来 | 时间模糊 | 需交代历史跨度时写具体年代 | 写具体年份 |
| 近年来，……越来越受到关注 | 关注度不等于问题 | 有具体数据（检索量、政策数） | 写数据，或删 |
| 在这个信息爆炸／快速变化的时代 | 纯装饰 | 无 | 删 |

## 2. 段首评论壳（强）

评论悬空，不回指上文。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 值得注意的是／需要指出的是／值得一提的是 | 自己给自己加提示音 | 后接的**确实是**反直觉发现 | 删壳，直接陈述；要连接就加"这" |
| 更重要的是／关键在于／问题在于 | 重要程度未经论证 | 前文确实铺垫了对比 | 删壳或写成"因为…所以…" |
| 不难发现／不难看出／由此可见 | 假装推理已完成 | 前文确有推理链 | 删，或补出推理 |
| 事实上／实际上／其实 | 暗示前文是假的 | 确有"表面 vs 实际"的对比 | 删；真有对比就写清两边 |
| 说白了／简单来说／一言以蔽之 | 口语壳替代逻辑 | 前文极复杂、确需降维 | 删，直接给结论 |
| 从这个角度看／从这个意义上说 | 视角声明无信息 | 确实换了分析单位 | 删，或写明"从成本看…" |

## 3. 逻辑连接陈词（弱，成片才处理）

一段里多数句子靠连接词起头，读着像念提纲。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 首先……其次……最后…… | 三项等长，常无材料 | 操作步骤、任务书分点 | 改成时间、因果、场景推进 |
| 一方面……另一方面…… | 假平衡 | 两边确有对立关系且都具体 | 只写有依据的一边 |
| 与此同时／在此基础上／具体而言 | 逻辑未明示就贴标签 | 确为同时发生或递进 | 删，让事情自己排先后 |
| 综上所述／总而言之／总的来说 | 复述前文 | 长报告需要导读 | 删；结尾给新结论或行动 |
| 因此／所以（连续三次以上） | 因果链未验证 | 确为因果 | 保留一处，其余还原为并列 |
| 不仅如此／更重要的是（递进连用） | 每句都在加码 | 无 | 删到只剩一层递进 |

## 4. 翻案对比（强）

制造一个没人持有的 X 再推翻，显得有洞见。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 不是X，而是Y／并非X，而是Y | 负半句没人主张过 | X 是真实误解，读者会因此做不同的事（"这不是退款，而是撤销授权"） | 删 X，直接写 Y；Y 仍空就整句删 |
| 与其说X，不如说Y | 同上，且更绕 | X 确为常见说法 | 写 Y |
| 看似X，实则Y／表面…实际上… | 预设读者被表象骗了 | 确有表象与实质的落差 | 写清落差的证据 |
| 你以为X，其实Y | 同上，且带说教 | 无 | 写 Y |
| 问题不在X，而在Y | 归因未论证 | 有排除 X 的证据 | 给证据，或只写 Y |
| 不仅是X，更是Y | 每句都拔高一层 | Y 有独立信息 | 删"不仅是X"，直接写 Y |
| X 固然重要，但 Y 更重要 | 假让步 | 两者确有取舍 | 写取舍条件 |
| 这不是简单的X，而是Y | 同上 | 无 | 写 Y |

## 5. 拔高与收束（强）

宣布重要，不说重要在哪。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 具有重要意义／具有重要的理论价值和实践意义 | 无对象无后果 | 公认历史评价（"载人登月的里程碑"） | 换成具体对象和后果；换不出就删 |
| 为……提供了有力支撑／保障 | 手段与结果未连接 | 有具体产出 | 写产出 |
| 助力……高质量发展／注入新动能 | 万能口号 | 政策原文引述 | 删 |
| 为……奠定了基础／开辟了新路径 | 未经证实的历史判断 | 有后续事实可指 | 删或写后续 |
| 起到了……的作用／发挥着重要作用 | 回避简单动词 | 无 | 改成"是""有""做了" |
| 在……中扮演着重要角色 | 同上 | 无 | 写具体做了什么 |
| 标志着……／意味着……（用于升华） | 普通事实被说成转折点 | 确有可核对的节点 | 写事实本身 |
| 彰显了／体现了／印证了 + 宏大对象 | 句尾补一条赞美 | 有材料支撑的具体判断 | 删尾巴，或写支撑它的数据 |
| 是……的重要组成部分 | 无信息归类 | 确为结构说明 | 删 |

## 6. 模糊归因（强）

用匿名权威替代证据。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 有研究表明／根据相关研究 | 来源不明 | 用户给了来源 | 写出作者、年份、期刊；没有就改成作者判断并写范围 |
| 专家认为／学者普遍认为／业内认为 | 权威无名 | 有人名职务 | 写名字；没有就删归因 |
| 大量实践证明／无数案例表明 | 数量不可核 | 有可数的案例 | 写出"我们试点的 3 个班" |
| 有数据显示／据统计 | 数据无源 | 有出处 | 写来源；没有就删 |
| 国内外研究一致认为 | 假共识 | 有综述支撑 | 写具体分歧与共识 |
| 用户反馈显示／很多人说 | 样本不可核 | 有样本量与方式 | 写"我问过的 6 位老师里 5 位…" |
| 相关人士透露／知情人士称 | 新闻腔误用 | 真正的报道语境 | 学术与说明文里删 |

## 7. 对冲免责（强，但别删过头）

不绑定具体主张的元层级免责，是 AI 的典型痕迹；**绑定具体主张的限定要留**。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 仅供参考／仅供参考之用 | 悬空免责 | 有具体时效或范围 | 改成带日期的来源 |
| 在一定程度上／从某种意义上说 | 无对象 | 后有具体范围（"在单卡上"） | 删壳，保留范围 |
| 可能／或许／也许（三层叠加） | 修补先前夸张 | 一层真实不确定性 | 收成一层，说明不确定来自哪 |
| 因人而异／视情况而定 | 立场真空 | 写出各情况分别是什么 | 写条件分支 |
| 各有优缺点／机遇与挑战并存 | 无判断 | 原文有材料支撑两边 | 写取舍条件或作者的判断 |
| 需要理性看待／辩证看待 | 空指令 | 无 | 删 |
| 有待进一步研究／仍需深入探讨 | 用展望代替结论 | 有具体的待研究问题 | 写出具体问题 |
| 由于篇幅所限／由于能力有限 | 自贬 | 真实限制（"本文只覆盖 2023 年以后"） | 改写成范围声明 |
| 以上仅为个人观点 | 重复免责 | 写给公众的政策解读，一次即可 | 全篇只留一次，放在开头或结尾 |

## 8. 元话语与导航（强）

写文档本身，不写它的主题。

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 本文将从三个方面／下文分为四部分 | 聊天机器人式导航 | 期刊、长报告要求 | 删；结构清楚时不需要预告 |
| 本节介绍／下面说明／接下来我们看 | 同上 | 长文档确实需要定位 | 删，标题已足够 |
| 需要说明的是／这里需要区分 | 元评论 | 确有易混点 | 直接给区分 |
| 换句话说／也就是说／简而言之 | 复述前句 | 换的确实是更易懂的说法 | 删；要换就直接用换后的说法 |
| 具体而言／更准确地说 | 同上 | 确有精确化 | 直接给精确版本 |
| 正如前文所述／如前所述 | 复述 | 长文档跨节回指 | 只留一次，其余删 |
| 下面用一个例子来说明 | 预告 | 无 | 直接给例子 |

## 9. 设问与悬念（弱，成片才处理）

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 那么问题来了／问题出在哪？ | 悬念替代内容 | 演讲、口播语境 | 直接给答案 |
| 为什么？因为…… | 自问自答 | 同上 | 合并成一句 |
| 答案可能出乎你的意料 | 制造期待 | 无 | 删 |
| 让我们拭目以待 | 空期待 | 无 | 删 |
| 你以为这就完了？ | 短视频腔 | 该平台确有此文体 | 删 |

## 10. 结尾升华（强）

| 句式 | 问题 | 保留条件 | 改法 |
|---|---|---|---|
| 未来可期／前景广阔／大有可为 | 用展望代替结论 | 有具体计划 | 写计划 |
| 让我们共同……／愿我们…… | 空号召 | 演讲稿 | 删 |
| 在这个……的过程中，我们…… | 抽象收束 | 无 | 停在最后一个具体事实 |
| 这不仅是一次……，更是一次…… | 拔高收束 | 无 | 删 |
| 相信在不久的将来…… | 未发生当已发生 | 无 | 删 |

## 11. 万能动词与搭配（弱，成片才处理）

`进行／实现／做出／采取／加以／给予／起到／发挥／形成 + 名词`（"对流程进行了优化"→"优化了流程"）；`扮演着／承载着／作为……的载体／展现出`（→"是""有""做了"）。

公文、法律文本里的固定搭配不动。

## 12. 高频抽象词（弱，密度触发）

赋能、助力、构建、打造、推动、促进、深化、强化、完善、融合、协同、多维、多元、全方位、系统化、精准化、智能化、高质量、新路径、新模式、新范式、新生态、闭环、抓手、引擎、底座、体系、生态、链路、心智、势能、飞轮。

**单个词不说明问题**；一句里出现四个以上，按"抽象词堆叠"处理：问清谁对什么做了什么，材料里有就写成动作和结果，没有就删句。

## 13. 滥用排比与三项式（弱）

三项排比、四字动宾连排（"突破了传统范式，填补了理论空白，创新了分析视角"）、"实现从A到B、从C到D、从E到F的转变"。

判据：每一项是否提供独立信息？并列项篇幅应与重要性成正比，不凑三项，也不硬砍成两项。

## 检测输出格式（只诊断时）

```
位置：第 3 段第 2 句
片段："值得注意的是，该方案在一定程度上…"
类别：段首评论壳（强） + 对冲免责（强）
问题：壳悬空，不回指上文；限定没有对象
改法：删"值得注意的是"，把"在一定程度上"换成具体条件
```

按影响读者判断的程度排序，先给最要紧的一到两处。没有问题就说没有问题。
