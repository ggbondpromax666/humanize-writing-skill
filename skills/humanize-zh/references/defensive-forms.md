# 防御性表述：识别、判别与改法

"拆防御"一步拿不准时读。

防御性写作指作者或模型**为了预先回避质疑**而写出的、不给读者新信息的文字：无对象的自贬、重复免责、层层对冲、虚设反方、流程自述、安抚。

它让中心判断被限定语、平衡句和免责声明遮住。反面**不是**"删掉所有限定"——必要边界（范围、条件、风险、未验证事项）是读者正确使用结论所需的信息，删了就是失真。

## 对冲悖论

AI 文本的问题**不是句内限定词多**，而是：

- **不绑定具体主张的元层级免责多**（"仅供参考""可能不够全面"）；
- **同时回避句内具体限定**（"在两个数据集上""样本来自单一学校"）。

所以一刀切删限定词会让文本更像 AI，还会把量化改成全称、把推测改成断言。

---

## 一、六道判别

按顺序问，任何一问得出"读者会少知道什么"，就不能删，只能写准。

### 1. 删除检验
> 这句删掉后，读者少知道了什么？

少了事实、范围、立场、后果、下一步中的任一项 → 保留并写准。什么都没少 → 填充。

### 2. 功能检验
> 它是在帮读者正确使用结论，还是在替反方论证、压低本文价值？

前者留，后者删。按句子**在当前位置的作用**判断，不按词表。"可能""在一定程度上"本身没有对错。

### 3. 五判据
省略后是否影响读者判断：
- 观点是否成立？
- 如何理解证据？
- 结论的适用范围？
- 研究设计是什么？
- 能否正确使用这个结果？

任一成立 → 保留。

### 4. 来源检验
- **来源标记型限定**（"据教务处通知""依照 2026 年 9 月官网页面""我没查最新数据，以官网为准"）→ 保留。
- **立场回避型限定**（"在一定程度上""某种意义上""或许"叠三个且没有对象）→ 删。

### 5. 位置检验
同一条限制**写一次**，放在读者需要它的位置。摘要、段首、结论里是高影响位置，省略会误导就留在当地；局限一节是正常位置。不把所有限定都挪到局限章节，也不在每段重复。

### 6. 信息强度分层
给每个主张标一层，用对应措辞：

| 层 | 措辞 | 例 |
|---|---|---|
| 材料直接显示 | 陈述句 | "图书角一个月登记了 143 次借阅" |
| 由材料合理推出 | "因此""说明" | "借阅集中在午休，所以午休时段开放最要紧" |
| 待验证 | "尚未""仍需" | "其他班是否同样适用尚未试过" |
| 必要边界 | "本文只讨论…" | "本文只讨论班级图书角，不涉及学校图书馆" |

**防御填充 = 不属于任何一层、只表达"我可能不够好"的句子。**

## 二、分类表

| 类型 | 中文形态 | 处理 |
|---|---|---|
| 无对象的自贬 | "仍有许多不足""水平有限""抛砖引玉""仅供参考""只是一个小小的尝试" | 删；真实限制改写成具体范围 |
| 重复免责 | 每段结尾"以上仅为个人观点"；同一条限制在摘要、引言、结论各说一遍 | 写一次，放在对应位置 |
| 虚设反方再否定 | "需要说明的是，本文并非否认…""当然，这并不是说…""笔者并不认为…"连续出现，而文中没人提出这些质疑 | 删防御；藏着真实主张就直说主张 |
| 立场真空 | "各有优缺点""因人而异""取决于多方面因素""见仁见智""机遇与挑战并存""需要理性看待" | 有具体选择条件就写条件；作者有判断就写判断；都没有就删 |
| 假平衡 | "一方面能提高效率，另一方面也对素养提出更高要求"两边都不具体；两件无对立关系的事硬排成一方面/另一方面 | 两边都落到材料，或只写有依据的一边 |
| 堆叠限定 | "可能在一定程度上潜在地对…产生某种程度的影响" | 收成一层，说明不确定性来自哪 |
| 装坦诚 | "说句实话""我必须诚实地说""缺点也说一句，免得你们说我恰饭" | 姿态删；自曝的缺点是真信息必须留 |
| 知识截止与资料有限 | "截至我的知识""目前公开资料有限，推测其…" | 整句删；承认没资料后不能再用猜测填空 |
| 流程自述与自我保证 | "本文由 AI 整理""未经核实处已标注""已保留原意，未改动事实" | 删；只保留改变读者下一步行动的提醒 |
| 安抚与方向认证 | "你已经走在正确的路上""完全不用担心""这是一个很好的开始" | 删，或改成"现有信息不足以判断"，不降格成"问题不大" |
| 先认不重要再拔高 | "虽然这只是初步探索，但它意义重大" | 删前半，后半按材料写 |
| 没人问的问题 | 在文中回答一个没有读者会提出的质疑 | 删 |

### 必须留的

| 类型 | 例 |
|---|---|
| 范围声明 | "本文只讨论课后作业""在已测试的两个数据集上" |
| 方法与样本局限 | "样本来自单一学校""未做消融实验，还无法认定提升来自模块 A" |
| 承担论证的概念区分 | "这不是退款，而是撤销尚未结算的授权" |
| 有证据的必要限定 | "这一结论只在 batch size 小于 64 时成立" |
| 安全法律学术说明 | "孕妇请遵医嘱""本研究经伦理委员会批准" |
| 请求里的真实让步 | "如果周五不方便，请告诉我"（删卑微措辞，留信息） |
| 真实更正 | "上一版把日期写错了，此处更正" |
| 来源标记 | "据教务处 9 月通知" |
| 真实的未完成与犹豫 | "延迟和错误率还没测出来，先继续观察" |
| 文种要求的说明 | 论文 limitations、工作总结"存在的问题" |
| 时间与统计范围 | "截至 2026 年 9 月""2024 至 2025 两个学年" |

## 三、改法：不只是删

- **正向范围**：把"不研究什么"写成"研究了什么"。
  `我们并不认为这些案例能代表所有城市` → `本文分析了 2023—2025 年 4 个城市的 11 个案例。`
- **说明不确定性来自哪里**：
  `这或许可能在一定程度上说明…` → `现有证据支持这一解释，但尚不能据此估计总体效应。`
- **条件句加断言**：
  `某种程度上可以认为效果不错` → `在单班试用的条件下，平均提交时间从 3 天降到 1 天。`
- **用带日期的来源替代免责语**：
  `以上开放时间仅供参考` → `以上来自场馆官网 8 月公告，出发前以当天公告为准。`
- **把约束写成可行性**（事实不变、方向翻转）：
  `本方法仅在单卡上运行` → `本方法单卡即可运行。`（前提：材料确实如此，且不隐去"多卡未测"）
- **优势要明说**：反防御的正面一半。有证据支持的优势，写出在什么条件下成立、为什么、解决了什么问题。
- **不用新套话填旧套话**：删"具有重要意义"后不补"具有里程碑意义"；删"仍有不足"后不补"未来可期"。

## 四、对称防线：不替作者变自信

拆防御最常见的失误是删过头。下面这些是**失真**，不是去 AI 味：

| 别把 | 改成 |
|---|---|
| "多数学生在第二周完成" | "学生在第二周完成" |
| "可能提升" | "提升" |
| "这可能是因为" | "这是因为" |
| "质的跃迁" | "变化" |
| "我反对" | "我持保留态度" |
| "还没测出来，先观察" | "效果良好" |
| "跨域效果尚未评估" | （删掉，因为它"看起来谨慎"） |

改完自问三条：

1. 有没有删掉影响结论成立的事实？
2. 有没有新增原文没有的主张？
3. 有没有超过这处问题需要的最小改动？

## 五、和"解释性表述"的边界

| | 防御性 | 解释性 |
|---|---|---|
| 动机 | 预先回避质疑 | 预先替读者补上下文 |
| 形态 | 自贬、免责、对冲、假平衡 | 复述、背景重讲、元话语、过度定义 |
| 判据 | 删掉后读者是否少了**立场/范围/后果** | 删掉后读者是否少了**新信息** |
| 改法 | 写准或删 | 删，或改成陈述事实 |

两者常常同时出现：`"值得注意的是，这项研究可能在一定程度上说明…（仅供参考）"`——前半是解释性元话语，后半是防御性对冲。

## 六、只诊断时的输出

每条：位置、原句片段（一字不改，≤20 字）、问题（平常话）、改法方向、必要时一句"这样改对读者判断的影响"。

分类名（"立场真空""方向认证"）只供你判断，不写给用户。
